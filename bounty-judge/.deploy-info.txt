v3 production-grade hardening (on top of v2):
- Refund: owner reclaims the reward when the reveal window closes with zero
  reveals (dead-end), so funds are never locked forever. Refunds are blocked
  once any answer is revealed (anti-rug): then the owner must judge + finalize.
- Verified llmInput: judgeAll binds the judging to the canonical revealed-answer
  set — stores answersHash (keccak over rubric + revealed participant/answer in
  order) + inputHash (keccak256(llmInput)) and emits both. Tampered/answer-
  swapping prompts become detectable off-chain. See getJudgingAttestation().

v2 changes (kept):
- Precompile address configurable (constructor param)
- IRitualWallet removed (unused); revealedCount O(1)
- Ritual ms-timestamp normalisation (block.timestamp > 1e12 => ms; _now() /1000)
